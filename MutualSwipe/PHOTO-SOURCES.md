# Starter deck photo sources

Each starter card with a photo uses one image from the place's own website, shrunk to 750×500 and bundled as `MutualSwipe/Starter/Photos/starter-<card id>.jpg`. Collected November 2026.

If an owner asks for a photo to come down, delete its file, set `photo: true` to false on that card in `Packages/MutualKit/Sources/MutualKit/Starter.swift` (the test counts photos, so update that number too), and ship an update. The card falls back to its color and initial.
